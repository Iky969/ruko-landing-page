Kenapa Ruko Berbeda dari Agent Lain?

Dirancang khusus untuk keamanan terminal mutlak, portabilitas tinggi, dan kecepatan tanpa kompromi.

🛡️

Dual-Layer Approval Gate & Guardian LLM

Mekanisme gerbang keamanan 2 lapis: Layer 1 Regex Gate menangkap seketika pola berisiko fatal (rm -rf /, mkfs, dd, fork-bomb) tanpa latensi. Perintah bernuansa seperti flag inline dievaluasi secara semantik oleh Layer 2 Guardian LLM terisolasi (temperature 0).

Arsitektur Evaluasi Perintah Shell Audit Log .ruko/guardian-audit.log (0600)
Shell Command → Layer 1: Regex Risk → Layer 2: Guardian LLM → Aman / Konfirmasi User
>_

Zero Runtime Dependencies

Murni dibangun dengan pustaka standar bawaan Node.js: node:fs, node:child_process, node:readline.

  • ✓ 0 MB node_modules saat runtime
  • ✓ Bebas dari supply-chain attack
  • ✓ Startup instan tanpa parse overhead
Immutable Security Core: Mengunci integritas modul saat startup.
🔒

Workspace Sandbox & Proteksi Kredensial

Menegakkan batasan ketat dengan assertInsideWorkspace(). Memblokir symlink traversal ke ../../etc/passwd atau ~/.ssh.

Blokir Akses Sensitif:
• .ruko/config.json & .env
• id_rsa, *.pem, *.key
• Blokir printenv & dump env
⏪

Snapshot Undo Otomatis

Setiap kali AI mengubah atau menghapus file, snapshot instan dicadangkan ke .ruko/undo/ dengan mode 0600.

Ketik /undo [path] untuk memulihkan file spesifik atau seluruh perubahan sesi dalam sekejap.
📱

Responsif Termux (40 Cols)

TUI Ruko dirancang adaptif. Status bar memotong teks secara proporsional agar tidak wrap-stacking bahkan di layar sempit Android Termux.

Dilengkapi ambient bottom tray, tree log ├── , dan ticker reasoning in-place.
